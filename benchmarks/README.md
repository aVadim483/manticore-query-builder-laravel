# Benchmarks нативного драйвера 4.x

Скрипты сравнивают нативный Laravel Query Builder с PDO и официальным HTTP-клиентом.
Отдельной зависимости от старого PHP-билдера нет. Прежние результаты сохранены
в [отчёте 3.x](results-3.x.md); они не характеризуют реализацию 4.x.

Новое [прямое A/B-сравнение 3.0.0 и 4.0.0](compare-versions/results-2026-10-26.md)
выполнено в одном окружении на одинаковых 20 000 документах: API, PDO-контроль, HTTP и очередь.
[Сценарии и методика](compare-versions/README.md) позволяют повторить измерения.

[Профиль пакетных INSERT/REPLACE](profile-writes/README.md) разбирает обнаруженную разницу
по этапам и содержит изолированный эксперимент ускорения числовых bindings; код библиотеки
в этом эксперименте не изменён.

[Повторные замеры после оптимизации построения SQL](profile-writes/optimized-results-2026-10-26.md)
сравнивают опубликованные версии с рабочими исходниками, где float компилируется в числовой литерал.

[Разделение подготовки SQL и выполнения PDO](sql-pipeline/results-2026-10-26.md) проверяет
шесть гипотез дальнейшей оптимизации на отдельных снимках, включая ограничения совместимости.

[Результаты реализованной пакетной подготовки](sql-pipeline/batch-writes.md) показывают
INSERT/REPLACE после упрощения cleanBindings и совместной сборки SQL и параметров.

## Запуск

```sh
composer install
composer --working-dir=benchmarks install
php -d xdebug.mode=off benchmarks/manticore_insert_pdo.php       200000 500
php -d xdebug.mode=off benchmarks/manticore_insert_qb.php        200000 500
php -d xdebug.mode=off benchmarks/manticore_insert_http_sql.php  200000 500
php -d xdebug.mode=off benchmarks/manticore_insert_http_json.php 200000 500
php -d xdebug.mode=off benchmarks/manticore_search_bench.php     2000 200000
```

Нужны SQL и HTTP Manticore. Адрес задаётся через `MANTICORE_TEST_HOST`,
`MANTICORE_TEST_PORT`, `MANTICORE_TEST_HTTP_PORT` (по умолчанию 127.0.0.1, 9306, 9308).
HTTP-скриптам дополнительно нужен официальный клиент из отдельного `benchmarks/composer.json`.
Нативный драйвер и PDO запускаются с корневой автозагрузкой без HTTP-клиента.

Скрипты создают и удаляют собственные таблицы `bench_*`. Не запускайте одновременно
несколько копий одного скрипта на одном сервере. Серверу нужны словари
`lemmatize_ru_all,lemmatize_en_all` для общей схемы.

## Что измеряется

Все клиенты используют одинаковую схему и детерминированные документы. PDO и нативный
драйвер работают через MySQL-протокол; официальный клиент — через HTTP SQL или JSON.

`manticore_insert_qb.php` сохраняет историческое имя, но теперь использует
`Database\\ManticoreConnection` и Laravel Query Builder. Без приложения Laravel создаётся
то же соединение с тем же Connector, что регистрирует провайдер. Схема прогревается до
измерения; преобразования атрибутов остаются включёнными. Для него выводится общее время
сборки и выполнения REPLACE: оно не разбивается на обмен и подготовку через старый ResultSet.

Поисковый скрипт сравнивает четыре клиента по MATCH, ранжированию и выдаче до 1000 строк.
Соединения прогреваются, клиенты чередуются, число итераций соблюдается точно.
Различие суммарного числа строк приводит к ошибке. PDO получает stdClass, нативный драйвер —
Collection<stdClass> с преобразованиями схемы; это часть измеряемой стоимости драйвера.

Сравнивайте общее время и распределение задержек на одном сервере. Для публикации фиксируйте
версии PHP/Laravel/Manticore, включённые библиотеки, транспорт и размер набора; повторите
прогоны несколько раз. Xdebug должен быть отключён. Проверки на малом наборе подтверждают
работоспособность скриптов, но не заменяют полноценное измерение производительности.
