# Проверка нативного драйвера

Основной набор загружает тот же `ServiceProvider`, который Laravel обнаруживает при установке
пакета. Проверяются SQL и параметры, контракты Laravel, запись/ID, транзакции, схема и миграции,
преобразования атрибутов, соединения, поиск, потоковое чтение и пагинация.
Bootstrap по умолчанию отклоняет загрузку классов удалённого PHP-билдера.

```sh
composer install
MANTICORE_TEST_HOST=127.0.0.1 MANTICORE_TEST_PORT=9306 MANTICORE_TEST_BUDDY=1 vendor/bin/phpunit --fail-on-skipped
```

CI независимо устанавливает Laravel 11, 12 и 13, включая PHP 8.2 на нижней границе и PHP 8.5
на верхней. Нужен сервер Manticore с Buddy и библиотекой KNN.
Затем каждый job проверяет изолированную production-установку:

```sh
php tests/prepare-production.php 13
composer update --working-dir=build/production --no-dev --prefer-dist --no-interaction
php tests/production-smoke.php build/production/vendor/autoload.php --live
```

Первый аргумент `11`, `12` или `13` выбирает версию Illuminate Database. Проверяемое приложение
устанавливает текущий пакет как path-зависимость без Testbench, PHPUnit и полного Laravel.
Smoke-тест регистрирует провайдер в минимальном контейнере Illuminate и проверяет ленивое
соединение, сборку запроса, а с `--live` — схему, запись и ID, JSON/MVA, метаданные поиска
и транзакцию. Уникальная тестовая таблица удаляется в `finally`.
Без `--live` соединение с сервером не открывается.

Для полного набора в отдельной установке задайте `MANTICORE_TEST_AUTOLOAD` — абсолютный путь
к её Composer-autoload. Запускайте её PHPUnit с `phpunit.xml.dist` репозитория и сопоставлением
PSR-4 `avadim\Manticore\Laravel\Tests\` с каталогом `tests/` текущего checkout.
Это исключает незаметную подмену версии Laravel корневым каталогом vendor.

2026-10-21 полный набор прошёл на PHP 8.4.19 с Laravel 11.57.0, 12.70.1 и 13.30.1:
по 130 тестов без ошибок и пропусков. Сервер: Manticore 29.9.0, Buddy 4.4.3, Columnar/KNN 14.2.1.
Другие версии PHP проверяет CI. Полноценная поддержка Eloquent не подтверждена.

[Benchmarks](../../benchmarks/README.md) отдельно проверены на 100 документах для каждой
вставки и 120 документах / 5 запросах на поисковый профиль. Четыре клиента обязаны вернуть
одинаковое число строк. Такой малый прогон проверяет скрипты, а не производительность.

## Совместимость с сервером

Минимальная поддерживаемая версия — **Manticore 28.6.6**, самый ранний проверенный сервер
для этого драйвера. Более старые версии находятся за границей поддержки; драйвер не отклоняет
их автоматически при каждом подключении. Функции сервера требуют соответствующих модулей
и настроек таблицы. См. [официальное описание 28.6.6](https://manticoresearch.com/blog/manticore-search-28-6-6/).

CI проверяет каждую из четырёх комбинаций PHP/Laravel на двух серверах:

| Цель | Образ | Назначение |
| --- | --- | --- |
| Минимум | `manticoresearch/manticore:28.6.6@sha256:341f333906fb2183fe585ad66de3486f372b2bbdd39e0e001d280a54f06d893a` | Воспроизводимая нижняя граница с комплектными модулями |
| Latest | `manticoresearch/manticore:latest` | Проверка текущего официального стабильного образа |

Перед тестами выполните `php tests/check-server.php`. Скрипт читает SHOW STATUS, отклоняет
сервер ниже 28.6.6, дожидается Buddy и KNN и выводит полные версии сервера и модулей.
Переменная `MANTICORE_TEST_EXPECTED_VERSION=28.6.6` требует точного совпадения для проверки
нижней границы. `MANTICORE_TEST_IMAGE` добавляет образ в отчёт, а `MANTICORE_TEST_SERVER_REPORT`
сохраняет его по указанному пути в существующем каталоге. Полный набор и production smoke
должны проходить без пропусков. В подключениях приложения дополнительного запроса версии нет.

Минимальный образ содержит Buddy 4.2.0 и Columnar/KNN 13.8.3. На 2026-10-21 digest `latest` —
`sha256:461b419739a2bbbffb4be0b32db26c41d7b435bf7fd1fce95b414ca5ccbb3775`:
Manticore 29.9.0, Buddy 4.4.3, Columnar/KNN 14.2.1. В CI этот job намеренно следует тегу,
а не закреплён за указанным digest; будущие обновления тега проверяются новыми прогонами.

Прогоны 2026-10-21 на PHP 8.4.19 прошли: минимальный сервер на Laravel 11/12/13 и указанный
`latest` на Laravel 13 — по 130 тестов / 628 проверок без пропусков. Production-установка
Illuminate 13.38.0 проверена на обоих серверах. Локально исполняемые файлы и комплектные
модули извлечены из официальных образов и запущены отдельными пользовательскими службами;
запуск контейнеров Docker и другие версии PHP проверяет CI.

Отдельно выполнена [миграция живого приложения](migration-app-verification.md): Laravel 12
сначала на 3.0.0, затем на опубликованной 4.0.0-alpha.1, с браузерными формами и сохранением
поисковых данных. Это самостоятельная проверка помимо матрицы пакета.

## Проверка расширенного Schema Builder

2026-10-22 ещё не выпущенный [расширенный API схемы](schema-alter.md) проверен полным набором
на PHP 8.4.19 в четырёх комбинациях: Manticore 28.6.6 с Laravel 11/12/13 и Manticore 29.9.0
с Laravel 13. В каждом прогоне **147 тестов / 749 проверок**, без пропусков.
Production-установка Illuminate 13.38.0 прошла на обоих серверах, включая чтение настроек,
расширение целочисленного типа и переименование таблицы туда и обратно.

Проверены сохранение 32/64-битных значений, актуализация исходной схемы, отказ для columnar
и неподдерживаемых типов, порядок настроек, отсутствие серверных defaults в результате,
частичные ошибки ALTER, сброс кеша после конфликта имён и применение/откат настоящих миграций
с таблицей учёта в SQLite. Откат намеренно сохраняет bigint вместо сужения типа.
Контракт протокола записан в [таблице совместимости](../schema-alter-compatibility.md).

На отдельном Manticore 29.9.0 с пустым `buddy_path` прошёл `php tests/schema-no-buddy.php`:
переименование вызывает `QueryException`, исходная таблица и документы сохраняются.
Скрипт запускается отдельно с `MANTICORE_TEST_HOST` и `MANTICORE_TEST_PORT`, указывающими
на тестовый экземпляр без Buddy; экземпляр с Buddy он отклоняет. В обычный прогон PHPUnit
с Buddy этот скрипт не входит. Временные службы совместимости после проверки остановлены,
постоянный тестовый сервер приложения сохранён.

## Проверка API родителя для Scout

[Контракт hybrid/replacement/capabilities](hybrid-and-index-replacement.md) имеет самостоятельные
тесты без Scout: фиксированные ранги weighted RRF, текстовые и только семантические документы,
общие фильтры, listeners метаданных, ошибки ветвей, страницы ограниченного окна, клонирование
схемы, reader в отдельном процессе во время rename, восстановление прерываний и настоящий
SQL-конфликт второго rename. Объявленное наличие модулей проверяется отдельно от read-only
probes; disconnect/reconnect/purge и DDL очищают результаты проверки.
Скрипт без Buddy также проверяет недоступность fuzzy/autocomplete. Production smoke выполняет
hybrid, HNSW probe и clone/switch/rollback без Testbench, Scout и самостоятельного PHP-билдера.
Существующая матрица из восьми CI-job выполняет проверки на всех поддерживаемых runtime
и minimum/latest перед публикацией alpha.2.

Окончательный код проверен 2026-10-22 на PHP 8.4.19: минимум с Laravel 11/12/13 и latest
29.9.0 с Laravel 13, по 160 тестов / 870 проверок без пропусков. Production-установки прошли
на обоих серверах. Другие версии PHP проверяет релизная матрица CI.

## Выполняемые примеры руководства hybrid (alpha.3)

`HybridGuideIntegrationTest` извлекает помеченные PHP-примеры из
[русского](hybrid-search.md) и [английского](../hybrid-search.md) руководств.
Он создаёт учебную таблицу со случайным изолированным префиксом, загружает документы,
переводит их в дисковый HNSW-chunk и выполняет примеры по порядку. Проверяются типы результата,
попадание семантических документов, общие фильтры, метаданные и пагинация. Затем таблица удаляется.
Примеры выполняются в существующей CI-матрице minimum/latest, включая расширенные настройки
KNN и вложенный диапазон, а не проверяются только на PHP-синтаксис.
