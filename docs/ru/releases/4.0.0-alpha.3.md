# 4.0.0-alpha.3

[English](../../releases/4.0.0-alpha.3.md)

Новая alpha вводит явные выполняющие hybrid-методы и отдельное
[руководство по гибридному поиску](../hybrid-search.md) с примерами от простых к сложным.
[Возможности сервера и замена RT-индекса](../hybrid-and-index-replacement.md) описаны отдельно.
Зависимость от Scout не добавляется.

## Изменения API относительно alpha.2

* `hybridSearch(...)` выполняет поиск сразу и возвращает `HybridResult` с оценками и метаданными.
* `hybridGet(...)` возвращает `Collection<stdClass>`, как `get()`.
* `hybridFirst(...)` возвращает лучший документ как `stdClass|null`, как `first()`.
* Прежний `hybrid(...)->search()` удалён без alias. Замените его на `hybridSearch(...)`.
  Обычные `search()`, `get()` и `first()` сохраняют прежние контракты.

First ранжирует полные окна кандидатов и только затем выбирает документ. Лимиты ветвей
до одного не уменьшаются. Объединение по-прежнему выполняется в PHP после двух отдельных
серверных поисков; `knn()->match()` остаётся пересечением. Total окна не является полным total объединения.

## Документация и исправления

Примеры идут от минимального вызова через первый документ, фильтры, один вес,
метаданные и пагинацию к расширенным опциям и синтаксису MATCH. Примеры обоих языков
выполняются интеграционным тестом на изолированных таблицах, включая дисковые HNSW-индексы.
Эта проверка выявила и исправила обработку строчного Laravel-типа `between` и сериализацию
целого значения oversampling: Manticore требует float-токен вида `2.0`.

Релиз использует существующую матрицу из восьми CI-job: PHP 8.2/8.3/8.4/8.5, Laravel 11–13
и minimum/latest Manticore, без пропусков обязательных тестов, с production smoke без dev-зависимостей.
Минимум Manticore остаётся 28.6.6. Самостоятельный PHP-билдер не требуется.

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-alpha.3
```

Это предварительный выпуск. Интеграция Scout и полноценная совместимость Eloquent не заявляются.
Замена RT-индекса по-прежнему требует обслуживания и блокировки силами приложения, имеет
промежуток между rename и не обещает атомарный swap или zero downtime.
См. [руководство перехода](../upgrading-3.x-to-4.x.md).
