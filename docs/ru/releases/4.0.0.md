# 4.0.0

[English](../../releases/4.0.0.md)

Стабильный нативный драйвер ManticoreSearch для Laravel заменяет обёртку 3.x и работает
напрямую через Laravel Database, Query Builder и PDO. Зависимость от самостоятельного
PHP-билдера удалена. Это мажорный выпуск с несовместимыми изменениями: используйте
[инструкцию перехода с 3.x](../upgrading-3.x-to-4.x.md).

```sh
composer require "avadim/manticore-query-builder-laravel:^4.0"
```

## Возможности

* `DB::connection('manticore')`, коллекции, cursor/lazy/chunk, пагинация, события запросов
  и Schema Builder с учётом миграций в основной SQL-базе приложения.
* Метаданные и фасеты `search()`, полнотекстовый `whereFullText()`, JSON-пути и `whereJson*()`.
* KNN, геопоиск, ранжирование/подсветка, CALL-помощники и ограниченный гибридный поиск через
  `hybridSearch()`, `hybridGet()` и `hybridFirst()`.
* `updateOrInsert()`, `replaceOrInsert()` и транзакционный эмулируемый `upsert()`.
* Расширенная RT-схема, проверка возможностей сервера и замена индекса под управлением приложения.
* [Профиль 299 методов Laravel](../laravel-api-audit.md) с явными исключениями для несовместимых
  операций и зафиксированными контрактами 19 fulltext/JSON/условных методов записи.

## Проверки и требования

Опубликованный пакет установлен через Composer в настоящее Laravel 12 приложение.
Миграция сохранила исходные документы и прошла прикладные, нативные API и браузерные
проверки. См. [руководство перехода](../upgrading-3.x-to-4.x.md).

[Нагрузочные проверки](../performance.md) охватывают чтение 5500 документов, 128-мерный HNSW,
1000 повторных операций и настоящий воркер на 120 заданий без роста памяти после прогрева.
CI проверяет PHP 8.2–8.5, Laravel 11–13 и minimum/latest Manticore, включая production-потребителей
минимальных Illuminate. Требования: PHP 8.2+, Laravel 11–13, Manticore 28.6.6+, PDO MySQL и JSON.
Для соответствующих возможностей нужны Buddy и библиотека KNN.

Upsert выполняет поиск и запись каждой строки без изоляции поисков; UPDATE на месте не
откатывается. Total hybrid ограничен окном кандидатов. Замена RT-таблиц требует обслуживания
и имеет промежуток между rename. Полноценная совместимость Eloquent и Lumen не входит
в проверенный профиль.
