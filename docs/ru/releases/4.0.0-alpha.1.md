# 4.0.0-alpha.1

Заметки описывают проверки на момент публикации. Последующая
[миграция живого Laravel-приложения](../migration-app-verification.md) уже проверена;
переход Scout-адаптера остаётся непроверенным.

Первая alpha нативного драйвера ManticoreSearch для Laravel Database предназначена для раннего
тестирования интеграции. До стабильной 4.0 API может меняться. Обновление реального приложения
и миграция Scout-адаптера пока не проверены и не входят в заявления о готовности версии.

## Что меняется

Используйте `DB::connection('manticore')`, Query Builder Laravel, результаты Collection/stdClass,
LazyCollection, пагинацию, события запросов и Schema Builder через PDO.
Драйвер больше не использует `avadim/manticore-query-builder-php`.

Старые псевдоним `ManticoreDb`, классы пакета Facade/Manager/Factory/Connection/Query/Row,
`config/manticore.php` и статический пул удалены. Конфигурация переносится в
`database.connections`; вызовы, типы и сериализация обновляются явно.
Перед обновлением прочитайте [руководство перехода с 3.x](../upgrading-3.x-to-4.x.md).

## Проверенная совместимость

| Laravel | PHP в CI | Серверы Manticore |
| --- | --- | --- |
| 11 | 8.2 | Закреплённая 28.6.6 и `latest` |
| 12 | 8.3 | Закреплённая 28.6.6 и `latest` |
| 13 | 8.4, 8.5 | Закреплённая 28.6.6 и `latest` |

Минимальная поддерживаемая версия сервера — 28.6.6. Официальный образ закреплён по digest
вместе с Buddy 4.2.0 и Columnar/KNN 13.8.3. Образ `latest` на 2026-10-21 содержит
Manticore 29.9.0, Buddy 4.4.3 и Columnar/KNN 14.2.1.
Нужны расширения PHP `pdo`, `pdo_mysql` и `json`. Другие комбинации PHP/Laravel ограничиваются
Composer-требованиями соответствующей версии фреймворка.

## Состояние возможностей

| Область | Поддержка в alpha |
| --- | --- |
| База данных | Именованные соединения, ленивый PDO, purge/reconnect, параметры и события |
| Чтение и запись | Результаты Laravel, CRUD, REPLACE, явные/автоматические ID, исключения SQL |
| Типы | JSON, MVA/MVA64, векторы, числа/bool и timestamp с кэшем схемы |
| Поиск | MATCH, веса/ranker, score, снимки метаданных, фасеты и подсветка хранимых полей |
| Помощники | Геопоиск, MVA ANY/ALL, KNN, KEYWORDS/SUGGEST/QSUGGEST/SNIPPETS/AUTOCOMPLETE, общий CALL |
| Большие результаты | Обход по offset/ID, buffered/unbuffered курсоры, ограниченная курсорная пагинация |
| Схема | CREATE/DROP, ALTER ADD/DROP, типы Manticore Blueprint, миграции Laravel |
| Транзакции | Один уровень, явные ошибки, без автоматического повтора и транзакционного DDL |

Для KNN нужны серверная библиотека и индексированный вектор; для AUTOCOMPLETE — Buddy и infixes.
Точные сигнатуры и ограничения приведены в [справочнике](../laravel-driver.md).

## Ограничения и непроверенные интеграции

* Миграция реального Laravel-приложения и совместимость Scout-адаптера ещё не проверены.
* Полноценные Eloquent, связи и сохранение моделей, Lumen и разделение чтения/записи не обещаются.
* Не поддержаны joins, unions, DISTINCT, блокировки, WHERE EXISTS, произвольный атомарный upsert
  и расширенные ALTER. Для полнотекстовых изменений используется REPLACE со сбросом пропущенных полей.
* Курсорная пагинация отклоняет float/строковые/JSON/MVA/вычисляемые ключи, группы/фасеты и KNN.
  Поддерживаемые выбранные integer/bool/timestamp ключи должны завершаться ID. Действуют окна сервера.
* Вложенные транзакции, savepoints, число попыток кроме одной и DDL в транзакции отклоняются.
* Исторические benchmarks 3.x не характеризуют производительность нативного драйвера.

## Проверки и установка

[Матрица CI из восьми job](https://github.com/aVadim483/manticore-query-builder-laravel/actions/runs/39661867437)
прошла для коммита драйвера `1031353`, включая живые тесты и production-установки.
Локальные прогоны совместимости: по 130 тестов / 628 проверок без пропусков.
Production-установка не использует Testbench, полный Laravel или самостоятельный PHP-билдер.
См. [инструкции проверок](../testing.md).

После публикации `v4.0.0-alpha.1` и индексации Packagist:

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-alpha.1
```

Явное ограничение prerelease не требует понижать глобальную стабильность приложения.
Сохраните основное SQL-соединение и таблицу учёта миграций, добавьте именованное соединение
Manticore по руководству перехода. Проверьте изменённые аргументы ID, исключения и типы результатов.
