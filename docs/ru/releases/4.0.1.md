# 4.0.1

[English](../../releases/4.0.1.md)

Патч ускоряет подготовку INSERT/REPLACE и упрощает документацию.
Публичный API нативного драйвера 4.x и требования к зависимостям сохранены.

```sh
composer require "avadim/manticore-query-builder-laravel:^4.0.1"
```

## Пакетная запись

- SQL и bindings нескольких строк подготавливаются совместно: колонки сортируются
  один раз, проверка одинакового порядка колонок используется повторно.
- Обработчик атрибута выбирается один раз на колонку в каждом пакете. Одиночная
  и пакетная запись используют общую валидацию JSON, MVA64, векторов и конечных чисел.
- Bindings очищаются за один проход с сохранением преобразования enum и индексов Laravel.
- Сохранены хуки билдера/Grammar, пользовательские выражения, callbacks и поведение
  метаданных пользовательских Connection через совместимые пути обработки.

Конечные скалярные float в INSERT/REPLACE билдера, включая варианты GetId, становятся
числовыми литералами при компиляции. В событиях и query log число находится в SQL
без отдельного float-параметра. Числа внутри JSON остаются JSON-параметрами; UPDATE,
фильтры и raw SQL сохраняют общую обработку числовых значений.

[Документ о производительности](../performance.md) отделяет актуальные замеры записи
от старых нагрузок. Результат зависит от схемы, размера пакета и окружения;
релиз не заявляет равенства производительности с 3.x.

## Документация и совместимость

Актуальные руководства использования, миграции, тестирования и производительности
заменяют завершённые эксперименты и дневники проверок предварительных выпусков.
[SQL-примеры для float](../float-values-sql.md) показывают, где число в кавычках
принимается, вызывает ошибку или оставляет прежнее значение без ошибки.
Для старых приложений сохранена [инструкция перехода с 3.x](../upgrading-3.x-to-4.x.md).

Изменения драйвера прошли по 240 тестов в восьми конфигурациях PHP/Laravel/Manticore,
контракты API и проверки production-установок. Требования прежние: PHP 8.2+,
Laravel 11–13, Manticore 28.6.6+, PDO MySQL и JSON. Для соответствующих функций
нужны Buddy/KNN; сохраняются [ограничения 4.0](4.0.0.md#проверки-и-требования).
