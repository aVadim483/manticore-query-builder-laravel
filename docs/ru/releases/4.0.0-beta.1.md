# 4.0.0-beta.1

[English](../../releases/4.0.0-beta.1.md)

Первая beta фиксирует публичный API 4.0 после проверки миграции живого приложения, аудита
унаследованных методов Laravel и ограниченных нагрузочных проверок. Нативный драйвер заменяет
обёртку 3.x; зависимость от самостоятельного PHP-билдера удалена.

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-beta.1
```

## Изменения после alpha.3

* `whereFullText()` / `orWhereFullText()` поддерживают поля, экранирование и вложенные текстовые условия.
* JSON-пути Laravel и `whereJson*()` используют параметры и документированные правила Manticore
  для membership, null, наличия ключей и длины массивов.
* `updateOrInsert()` и `replaceOrInsert()` явно разделяют частичное обновление и полную замену.
  Эмулируемый `upsert()` сохраняет необновляемые stored-поля и объединяет INSERT/REPLACE
  транзакцией, включая правила отката внешней транзакции.
* [Профиль Laravel API](../laravel-api-audit.md) описывает 299 методов. Неподдерживаемые
  операции и условия записи вызывают исключения: фильтрованный TRUNCATE и игнорируемые
  GROUP BY/окна не принимаются молча. CI проверяет контракты 19 методов.
* Вложенные MATCH/JSON bindings не дублируются. Проверка TEXT/columnar UPDATE действует
  при отключённых cast. Для раннего Laravel 11 добавлены JSON overlap-алиасы и единое
  поведение after-query callbacks. Ошибки hybrid перечисляют неизвестные ключи.

## Проверки

[Приложение с теми же 2105 документами](../migration-app-verification.md) прошло 32 сценария
на 3.0.0 и текущей 4.x: совпали 31 сравнимый результат, пройдены браузерные сценарии до/после
и дополнительные нативные проверки. [Нагрузочный отчёт](../performance.md) содержит чтение
5500 документов, 128-мерный HNSW, 1000 повторных операций и настоящий воркер на 120 заданий.
Матрица из восьми CI-job проверяет PHP 8.2–8.5, Laravel 11–13 и minimum/latest Manticore;
отдельно проверяются production-потребители минимальных Illuminate 11.0.0/12.0.0/13.0.0.

Это предварительный выпуск. Следующий этап — установка этой опубликованной версии в тестовое
приложение через Composer. Для перехода используйте [инструкцию 3.x → 4.x](../upgrading-3.x-to-4.x.md).
Минимальный Manticore — 28.6.6. Upsert выполняет поиск/запись для каждой строки и не изолирует
поиски; UPDATE на месте не откатывается. Total hybrid ограничен окном кандидатов. Замена
RT-таблиц требует управления обслуживанием со стороны приложения и имеет промежуток между
rename. Полноценная совместимость с Eloquent и Lumen не входит в проверенный профиль.
