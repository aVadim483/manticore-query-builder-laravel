# 4.0.0-rc.1

[English](../../releases/4.0.0-rc.1.md)

Кандидат в стабильный выпуск сохраняет код драйвера и публичный API beta.1. Опубликованная
beta установлена через Composer в живое Laravel-приложение и прошла 32 прикладных, шесть
нативных, восемь новых API и 11 браузерных проверок. Повторный прогон воркера на 120 заданий
не выявил роста памяти после прогрева. См. [проверку опубликованных пакетов](../release-verification.md).

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-rc.1
```

Финальный этап перед стабильной версией — установка и проверка этого опубликованного RC.
Требования: PHP 8.2+, Laravel 11–13 и Manticore 28.6.6+. См. [переход с 3.x](../upgrading-3.x-to-4.x.md),
[профиль API](../laravel-api-audit.md) и [нагрузочные замеры](../performance.md).
Upsert выполняет поиск каждой строки без изоляции поисков. UPDATE не откатывается.
Total hybrid ограничен окном кандидатов; замена RT-таблиц требует обслуживания и имеет
промежуток между rename.
