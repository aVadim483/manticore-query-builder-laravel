# Проверка опубликованных пакетов

[English](../release-verification.md)

После [проверки миграции с 3.x](migration-app-verification.md) опубликованные пакеты
установлены в то же приложение через Composer. Локальные path/package-репозитории и правки
vendor не использовались. В lock-файле менялась только эта зависимость; сохранены Laravel
12.70.1, PHP CLI 8.3.6, PHP-FPM 8.4.27 и Manticore 29.9.0.

| Опубликованный пакет | Git source reference | Прикладные / нативные / новые API / браузерные проверки |
| --- | --- | --- |
| 4.0.0-beta.1 | `cbbf0e0fa2545914c3dec09e292767c991cff286` | 32 / 6 / 8 / 11, все прошли |

На beta также повторно проверен настоящий воркер: 120 заданий в одном процессе,
прирост удерживаемой и выделенной памяти после задания 20 — 0.
Границы замеров описаны в [нагрузочном отчёте](performance.md).

Все 31 сравнимый результат совпали с исходной 3.0.0; изменённый контракт Row/Generator
проверен отдельно. Все 2105 исходных документов и их SHA-256 сохранены. Байты установленного
пакета сверены с точным Git-тегом: manifest из `composer.json` и 31 файла `src` имеет SHA-256
`55a071ceb4cb71a67f893779027c94e8800cdb7abeb29a591f5f397bca7a8c79`.
У раннего рабочего снимка другой байтовый отпечаток из-за смешанных переводов строк в одном
файле; после нормализации его содержимое совпадает с опубликованным кодом драйвера.

[Публичный отчёт](https://manticore.avadim.ru/?report=1) показывает установленную версию,
браузерные результаты и source reference. Отчёты по версиям и резервные копии vendor/lock
сохранены в приватной части тестового приложения. Проверки подтверждают работу этого
приложения и документированного профиля драйвера; полноценная совместимость Eloquent и
Lumen не заявляется.
