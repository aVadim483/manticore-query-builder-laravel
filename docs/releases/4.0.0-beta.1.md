# 4.0.0-beta.1

[Русский](../ru/releases/4.0.0-beta.1.md)

The first beta freezes the 4.0 public API after live application migration, inherited Laravel
API review and bounded performance/worker checks. The native driver replaces the 3.x wrapper
and has no standalone PHP-builder dependency.

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-beta.1
```

## Changes since alpha.3

* `whereFullText()` / `orWhereFullText()` compile scoped, escaped and nested text conditions.
* Laravel-style JSON paths and `whereJson*()` methods use bound values and documented
  Manticore semantics for membership, nulls, key checks and array lengths.
* `updateOrInsert()` and `replaceOrInsert()` provide explicit partial-update/full-replacement
  behavior. Emulated `upsert()` preserves non-updated stored fields and stages INSERT/REPLACE
  in one transaction, including caller-transaction rollback behavior.
* A [reviewed Laravel API profile](../laravel-api-audit.md) covers 299 methods. Unsupported
  inherited operations and write clauses fail explicitly; no filtered TRUNCATE or ignored
  grouping/window clauses are silently accepted. CI checks 19 frozen method contracts.
* Nested MATCH/JSON bindings are not duplicated. TEXT/columnar update guards remain active
  with casts disabled. Earliest Laravel 11 releases receive missing JSON overlap aliases and
  consistent after-query callback behavior. Unknown hybrid options identify their keys.

## Verification

The [same 2,105-document application](../migration-app-verification.md) passed 32 scenarios on
3.0.0 and current 4.x, with 31 comparable results matching, browser checks before/after and
additional native/current-API checks. The [performance report](../performance.md) records
5,500-document reads, 128-dimensional HNSW, 1,000 repeated operations and a real 120-job worker.
The eight-job CI matrix covers PHP 8.2–8.5, Laravel 11–13 and minimum/latest Manticore;
minimum Illuminate 11.0.0/12.0.0/13.0.0 production consumers are checked separately.

This is a prerelease. The next gate is installation of this published version in the test
application through Composer. Use the [3.x migration guide](../upgrading-3.x-to-4.x.md).
Minimum Manticore remains 28.6.6. Upsert performs per-row lookups/writes and does not provide
search isolation; in-place UPDATE cannot be rolled back. Hybrid totals cover bounded windows.
RT replacement needs application-managed maintenance and has a rename gap. General Eloquent
and Lumen compatibility are outside the verified profile.
