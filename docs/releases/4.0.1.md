# 4.0.1

[Русский](../ru/releases/4.0.1.md)

This patch optimizes INSERT/REPLACE preparation and simplifies the documentation.
The native 4.x public API and dependency requirements are unchanged.

```sh
composer require "avadim/manticore-query-builder-laravel:^4.0.1"
```

## Bulk writes

- Prepare multi-row SQL and bindings together, sorting columns once and reusing
  validation for matching row layouts.
- Select attribute encoders once per column per write batch. Single-value and batch
  encoding share validation, including JSON, MVA64, vectors and finite numbers.
- Clean bindings in one pass while preserving Laravel's enum conversion and indexes.
- Preserve builder/Grammar hooks, custom expressions, callbacks and custom connection
  metadata behavior through compatible fallback paths.

Finite scalar floats in builder INSERT/REPLACE, including GetId variants, are now numeric
SQL literals at compilation time. Query events and logs contain the literal in SQL
without a separate float binding. JSON numbers remain JSON-bound values; UPDATE,
filters and raw SQL retain the general numeric handling.

The [performance guide](../performance.md) separates current write measurements from
older workloads. Results depend on schema, batch size and environment; this release
does not claim performance parity with 3.x.

## Documentation and compatibility

Current usage, migration, testing and performance guides replace completed experiment
reports and prerelease verification diaries. The [SQL float examples (Russian)](../ru/float-values-sql.md)
show where quoted numbers work, fail or silently leave values unchanged.
The [3.x migration guide](../upgrading-3.x-to-4.x.md) remains the entry point for old applications.

Runtime changes passed 240 tests in each of eight PHP/Laravel/Manticore configurations,
API contracts and production-only consumer checks. Requirements remain PHP 8.2+,
Laravel 11–13 and Manticore 28.6.6+ with PDO MySQL and JSON. Feature-specific Buddy/KNN
requirements and the [4.0 limitations](4.0.0.md#release-evidence-and-requirements) still apply.
