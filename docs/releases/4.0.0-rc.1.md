# 4.0.0-rc.1

[Русский](../ru/releases/4.0.0-rc.1.md)

This release candidate preserves the runtime code and public API of beta.1. The published
beta package was installed through Composer in the live Laravel application and passed
32 application, six native, eight current-API and 11 browser checks. A second 120-job worker
run found no retained-memory growth after warm-up. See [published-package evidence](../release-verification.md).

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-rc.1
```

The final release gate is installation and verification of this published RC. Requirements
remain PHP 8.2+, Laravel 11–13 and Manticore 28.6.6+. Read the [migration guide](../upgrading-3.x-to-4.x.md),
[API profile](../laravel-api-audit.md) and [performance report](../performance.md).
Upsert uses per-row lookups and does not isolate searches. UPDATE cannot be rolled back.
Hybrid totals cover candidate windows; RT replacement requires maintenance and has a rename gap.
