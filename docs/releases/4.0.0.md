# 4.0.0

[Русский](../ru/releases/4.0.0.md)

The stable native ManticoreSearch driver for Laravel replaces the 3.x wrapper and uses
Laravel Database, Query Builder and PDO directly. The standalone PHP-builder dependency
is removed. This is a breaking major release; follow the [3.x migration guide](../upgrading-3.x-to-4.x.md).

```sh
composer require "avadim/manticore-query-builder-laravel:^4.0"
```

## Included API

* `DB::connection('manticore')`, native collections, cursor/lazy/chunk reads, pagination,
  query events and Schema Builder with explicit primary-database migration bookkeeping.
* `search()` metadata/facets, scoped `whereFullText()`, JSON arrow paths and `whereJson*()`.
* KNN, geo, text ranking/highlighting, CALL helpers and bounded terminal hybrid methods:
  `hybridSearch()`, `hybridGet()` and `hybridFirst()`.
* `updateOrInsert()`, `replaceOrInsert()` and transactional emulated `upsert()`.
* Extended RT schema operations, capability evidence and maintenance-managed index replacement.
* A [reviewed 299-method Laravel API profile](../laravel-api-audit.md) with explicit rejection
  of unsupported operations and frozen contracts for 19 full-text/JSON/conditional-write methods.

## Release evidence and requirements

Runtime code and dependencies are unchanged from verified beta.1 and rc.1. Both published
packages were installed through Composer in the real Laravel test application and passed
32 application, six native, eight current-API and 11 browser checks. All 31 comparable results
matched the original 3.0.0 baseline and all 2,105 documents were preserved.
See [published-package evidence](../release-verification.md) and [migration evidence](../migration-app-verification.md).

[Performance checks](../performance.md) cover 5,500-document reads, 128-dimensional HNSW,
1,000 repeated operations and a real 120-job worker without retained-memory growth after warm-up.
CI covers PHP 8.2–8.5, Laravel 11–13 and minimum/latest Manticore, including minimum Illuminate
production consumers. Requirements: PHP 8.2+, Laravel 11–13, Manticore 28.6.6+, PDO MySQL and JSON.
Buddy/KNN modules are needed for their respective features.

Upsert performs per-row lookups and writes without search isolation; in-place UPDATE cannot
be rolled back. Hybrid totals describe candidate windows. RT replacement requires maintenance
and has a rename gap. General Eloquent and Lumen compatibility are outside the verified profile.
