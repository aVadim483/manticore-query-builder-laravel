# 4.0.0-alpha.1

First alpha of the native ManticoreSearch driver for Laravel Database. This release is for early
integration testing. The API may change before 4.0 stable. A real application upgrade and a
Scout adapter migration have not yet been validated and are not release claims.

## What changes

Use `DB::connection('manticore')`, Laravel's Query Builder, Collection/stdClass results,
LazyCollection, pagination, query events and Schema Builder over PDO. The driver no longer
uses `avadim/manticore-query-builder-php`.

The 3.x `ManticoreDb` alias, package Facade/Manager/Factory/Connection/Query/Row,
`config/manticore.php` and static connection pool have been removed. Applications must move
configuration to `database.connections` and update callers, types and serializers explicitly.
Read the [3.x migration guide](../upgrading-3.x-to-4.x.md) before updating.

## Verified compatibility

| Laravel | PHP tested in CI | Manticore targets |
| --- | --- | --- |
| 11 | 8.2 | Pinned 28.6.6 and `latest` |
| 12 | 8.3 | Pinned 28.6.6 and `latest` |
| 13 | 8.4, 8.5 | Pinned 28.6.6 and `latest` |

The supported server floor is 28.6.6. Its official image is pinned by digest, including
Buddy 4.2.0 and Columnar/KNN 13.8.3. The `latest` image observed on 2026-10-21 contains
Manticore 29.9.0, Buddy 4.4.3 and Columnar/KNN 14.2.1.
PHP extensions `pdo`, `pdo_mysql` and `json` are required. Other framework/PHP combinations
remain subject to each framework's Composer requirements.

## Feature status

| Area | Alpha scope |
| --- | --- |
| Database | Named connections, lazy PDO, purge/reconnect, bound queries and events |
| Reads/writes | Standard Laravel results, CRUD, REPLACE, explicit/automatic IDs and SQL exceptions |
| Types | Schema-cached JSON, MVA/MVA64, vector, numeric/bool and timestamp conversion |
| Search | MATCH, weights/rankers, scores, metadata snapshots, facets, stored-field highlighting |
| Helpers | Geo, MVA ANY/ALL, KNN, KEYWORDS/SUGGEST/QSUGGEST/SNIPPETS/AUTOCOMPLETE and generic CALL |
| Large results | Offset/ID walks, buffered/unbuffered cursor lifetimes and constrained cursor pagination |
| Schema | CREATE/DROP, ALTER ADD/DROP, Manticore Blueprint types and Laravel migrations |
| Transactions | Single level, explicit errors, no automatic replay and no transactional DDL |

KNN needs its server library and an indexed vector; AUTOCOMPLETE needs Buddy and table infixes.
See the [driver reference](../laravel-driver.md) for signatures and exact limits.

## Known limits and unverified integrations

* A real Laravel application's migration and Scout adapter compatibility are still unverified.
* General Eloquent, relationships, model persistence, Lumen and read/write splitting are not promised.
* Joins, unions, DISTINCT, locks, WHERE EXISTS, arbitrary atomic upsert and extended ALTER operations
  are unsupported. Full-text changes use REPLACE, which resets omitted attributes.
* Cursor pagination rejects float/string/JSON/MVA/computed keys, groups/facets and KNN; supported
  selected integer/bool/timestamp keys must end in ID. Server result-window limits still apply.
* Nested transactions, savepoints, retry counts other than one and DDL in a transaction are rejected.
* Historical 3.x benchmark results are not native-driver performance claims.

## Validation and installation

The [eight-job CI matrix](https://github.com/aVadim483/manticore-query-builder-laravel/actions/runs/39661867437)
passed for the driver commit `1031353`, including live tests and production-only consumers.
Local compatibility runs passed 130 tests / 628 assertions per run without skips. Production
consumers have no Testbench, full Laravel framework or standalone PHP builder dependency.
See [verification instructions](../testing.md).

After publication of `v4.0.0-alpha.1` and Packagist indexing:

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-alpha.1
```

This explicit prerelease constraint does not require lowering the application's global stability.
Keep the primary SQL connection and migration repository; add the named Manticore connection
from the migration guide. Review changed ID arguments, exception handling and row/collection types.
