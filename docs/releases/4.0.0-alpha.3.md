# 4.0.0-alpha.3

[Русский](../ru/releases/4.0.0-alpha.3.md)

This alpha introduces explicit terminal hybrid methods and a dedicated beginner-to-advanced
[hybrid search guide](../hybrid-search.md). Server capabilities and RT replacement remain in
[their own reference](../hybrid-and-index-replacement.md). No Scout dependency is added.

## API changes from alpha.2

* `hybridSearch(...)` executes immediately and returns `HybridResult` with scores and metadata.
* `hybridGet(...)` returns `Collection<stdClass>`, like `get()`.
* `hybridFirst(...)` returns the best document as `stdClass|null`, like `first()`.
* The former `hybrid(...)->search()` API is removed without an alias. Replace it with
  `hybridSearch(...)`; ordinary `search()`, `get()` and `first()` are unchanged.

First still ranks the full candidate windows before selecting a document. Neither candidate
limit is reduced to one. Hybrid fusion remains two independent server searches merged in PHP;
`knn()->match()` remains intersection. Candidate-window totals are not full-union totals.

## Documentation and fixes

Examples progress through a minimal call, first result, filters, one weight, metadata,
pagination, advanced text/KNN settings and extended MATCH syntax. Both languages' snippets
are executed against isolated tables by an integration test, including disk HNSW indexes.
This uncovered and fixed lowercase Laravel `between` validation and whole-number
oversampling serialization: Manticore requires a float token such as `2.0`.

The release uses the existing eight-job PHP 8.2/8.3/8.4/8.5, Laravel 11–13 and minimum/latest
Manticore matrix, with no skipped required tests and production-only consumer smoke checks.
Minimum Manticore remains 28.6.6. The standalone PHP builder remains absent.

```sh
composer require avadim/manticore-query-builder-laravel:4.0.0-alpha.3
```

This is a prerelease. Scout integration and general Eloquent compatibility are not claimed.
RT replacement still requires application-managed maintenance/locking and has a rename gap;
it is not an atomic swap or zero-downtime mechanism. See the [migration guide](../upgrading-3.x-to-4.x.md).
